
# COVID-19 Data Analysis & Tableau Dashboard

## 📌 Overview

Analyzed global COVID-19 data to identify trends in cases, deaths, infection rates, and population impact across countries and continents.

## 🛠️ Tools

- SQL Server
- Excel
- Tableau

## 📊 Analysis

- Total COVID-19 cases and deaths
- Death percentage
- Percentage of population infected
- Country and continent comparisons
- COVID-19 trends from 2020–2026
- Tableau forecasting through 2028

## 📈 Tableau Dashboard

Created an interactive Tableau dashboard with:

- Country filters
- Time-series visualizations
- Population infection percentage
- Country comparisons
- Forecasting for 2027–2028
